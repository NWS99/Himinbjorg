# Verified agent learnings

This file is controlled, agent-maintained operational memory. Store only reproducible, repository-local observations. Every learning needs an issue reference, date, evidence, and affected scope. Architecture decisions, product requirements, and security-policy changes do not belong here. Keep speculative observations in the Linear issue. Mark obsolete findings **Superseded** instead of silently rewriting them.

No initial learnings are recorded. The repository baseline and commands must be verified by the agent doing the work.

## Entry template

### YYYY-MM-DD — short title

- **Date:** YYYY-MM-DD
- **Linear issue:** N-XXX
- **Scope:** repository path, component, or command
- **Observation:** reproducible fact
- **Evidence or reproduction:** exact command, fixture, revision, or other evidence
- **Operational consequence:** action this fact supports
- **Status:** Proposed | Verified | Superseded
- **Superseded by:** N-XXX or `N/A`
